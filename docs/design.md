# 디자인 가이드 — "불 켜진 창문들"

> 화면을 만들 때 이 문서를 따른다. 여기 없는 결정은 이 문서의 컨셉에 맞게 고르고, 크게 벗어나면 사용자에게 먼저 묻는다.

## 1. 컨셉

전북대 학생들이 공강 시간에 잠깐 들러 쉬는 **귀여운 픽셀 건물**이다 (2026-11-25 결정: 오트밀 톤에서 **파스텔 픽셀**로 바꿈). 크림 바탕에 딸기 분홍·민트·하늘색, 진한 보라 테두리와 흐림 없는 그림자로 옛날 게임 화면 같은 느낌을 낸다. 긴 글(채팅·설명·플래너 일정)은 읽기 쉬운 글꼴로 남긴다.

- **로비 = 건물 외벽.** 방 하나하나가 픽셀 창틀의 **창문**이다. 켜진 창문 유리에는 반짝임 두 칸, 게임 중이면 분홍·민트 반반.
- **방 안 = 휴게실.** 상자마다 픽셀 테두리와 그림자, 채팅 말풍선도 각진 상자.
- 화려한 효과를 여기저기 뿌리지 않는다. 힘을 주는 곳은 "창문 로비"와 "창문으로 들어가는 전환" 두 곳뿐이다.

## 2. 디자인 토큰

색과 글꼴은 **CSS 변수로 `apps/web/src/shared/styles/tokens.css`에 한 번만 정의**하고, 모든 화면은 변수만 쓴다. 색 값을 컴포넌트에 직접 쓰지 않는다. 캠퍼스 플래너도 같은 파일을 쓴다. 픽셀 테두리·그림자를 입히는 목록은 `shared/styles/pixel.css` 한 파일에 모았다 (화면 CSS보다 나중에 불러온다).

### 색 (파스텔 픽셀) — 글자 대비는 모두 4.5:1 이상으로 계산해 맞췄다

| 변수 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--color-bg` | `#FFF4E6` | 기본 배경 (크림). 위에 분홍·민트 픽셀 점무늬 |
| `--color-surface` | `#FFFDF8` | 패널, 채팅창, 버튼 바탕 |
| `--color-surface-2` | `#F7E3EC` | 말풍선, 선택된 항목, 패널 안 구분 영역 (연분홍) |
| `--color-text` | `#3D2C4E` | 본문 글자 (진한 보라) |
| `--color-text-muted` | `#6B5A7B` | 보조 글자, 시간, 안내 |
| `--color-light` | `#FF9FBF` | 강조 (딸기 분홍). 주요 버튼, 재생 중, 켜진 창문, 선택된 탭 |
| `--color-light-text` | `#3D2C4E` | 분홍 위 글자 |
| `--color-light-ink` | `#B4326A` | 강조색을 **글자**로 쓸 때, 포커스 테두리 |
| `--color-sofa` | `#9EE0C9` | 보조 강조 (민트). 게임 중 창문, 안내 토스트 바탕 |
| `--color-sofa-ink` | `#2F7A63` | 민트를 글자로 쓸 때 (플래너 "과제") |
| `--color-cool-fill` / `--color-cool` | `#A9D8F5` / `#2F6690` | 하늘색 바탕(플래너 입구) / 하늘색 글자(달력 토요일) |
| `--color-online` | `#2F7A4E` | 접속 중, 성공 |
| `--color-danger` | `#B0322A` | 잠금, 강퇴, 오류 |
| `--color-warn` | `#8A5A00` | 곧 마감 (플래너) |
| `--color-line` | `#3D2C4E` | 픽셀 테두리와 그림자 색 |

### 글꼴

| 변수 | 글꼴 | 쓰는 곳 |
| --- | --- | --- |
| `--font-pixel` | **갈무리11 (Galmuri11)**, 한글 픽셀 글꼴, OFL-1.1 무료 공개 (jsDelivr `galmuri@2.40.3`) | 제목(h1~h3), 버튼, 탭, 대화상자 제목, 게임 화면 글자, 창문 아래 방 이름, 방 코드 |
| `--font-sign` | **갈무리14**, 대체 갈무리11 | 간판(`.sign`) |
| `--font-ui` | **SUIT** (가변 글꼴), 대체 `system-ui` | 채팅, 설명, 입력창, 플래너 일정처럼 긴 글 |

- 픽셀 글꼴은 기본 크기 12px의 **배수(24·36px)**일 때 픽셀이 또렷하다. 큰 제목은 이 크기로 쓴다 (메인 36px, 로비·방 이름 24px).
- 글자 크기 단계(본문 쪽): 12 / 14 / 16 / 20 / 28 / 40px.
- 영어 대문자 라벨, 제목 속 한 단어만 색 바꾸기, 제목 위의 작은 장식 라벨은 쓰지 않는다.

### 모양

- 모서리: **전부 0** (작은 점·색 고르기 칸도 네모 픽셀).
- 테두리: 큰 상자·버튼·입력창 `3px`(`--pixel`), 작은 칸(말풍선·점수 칩) `2px`, 모두 `--color-line`.
- 그림자: 흐림 없이 오른쪽 아래로 `3px`(`--pixel-shadow`), 대화상자·창문·입구 문은 `5px`. 버튼을 누르면 그림자 쪽으로 쑥 들어간다(`translate(3px, 3px)` + 그림자 없앰).
- 간격 단위: 4px의 배수 (4, 8, 12, 16, 24, 32, 48).

### 창문 카드 상태

| 상태 | 모양 |
| --- | --- |
| 입장 가능 | 창문 안이 `--color-light`로 켜짐. 인원이 많을수록 더 밝게 (불투명도 단계 3개 정도) |
| 게임 진행 중 | 창문 안에 `--color-sofa` 빛이 섞임 + "진행 중" 표시 |
| 인원 가득 | 불은 켜져 있지만 창문 아래 인원이 `--color-text-muted`, 누르면 "방이 가득 찼어요" |
| 잠긴 방 | 블라인드가 내려진 창문(가로줄 무늬) + 자물쇠 아이콘. 목록 아래쪽에 배치 |

- 창문 아래에는 방 이름(픽셀 글꼴), 인원, 재생 중인 곡 또는 진행 중인 게임을 짧게.
- 정렬: 입장 가능한 방이 앞, 잠긴 방이 뒤. 필터 "입장 가능한 방만 보기".
- 방이 없을 때: 불 꺼진 창문들만 보이고 "아직 불 켜진 방이 없어요. 첫 방을 열어볼까요?" + [방 만들기].
- 휴대폰: 창문을 한 줄에 2개씩.

### 데스크톱

┌──────────────────────────────────────────────┬──────────────┐

게임 중

```
┌──────────────────────────────────────────────┬──────────────┐
│ 공강방 👑방장 · 4/8 [초대][설정][나가기] (♪ 곡 제목 ❚❚ ▶▶ 🔇 대기 2 [신청]) │  참가자 ▾  │
│                                   └ 얇은 진행선 ┘ │    채팅        │
├──────────────────────────────────────────────┤              │
│                                              │              │
│            게임 화면 (남은 공간 전부)              │              │
│                                              │ [메시지 입력]   │
└──────────────────────────────────────────────┴──────────────┘
```

- **오른쪽 칸 탭** (넓은 화면, 2026-11-25): 오른쪽 칸 맨 위에 **[방 채팅 | 친구 N ①]** 탭. 방 채팅 탭은 위 그림 그대로(참가자 + 채팅), 친구 탭은 친구 현황판(목록·1:1 대화)이 칸을 채운다. 방 채팅은 탭을 바꿔도 그대로 남고(쓰던 메시지 유지), 친구 탭은 볼 때만 띄운다. 방 밖(메인·로비)에서는 친구 현황판이 화면 오른쪽에 따로 펼쳐진다.
- **라운지 TV**: 평소에는 방 안의 TV처럼 테두리를 둔 하나의 물건으로 크게 보여준다. 가로는 가운데, 세로는 헤더 바로 아래(채팅과 윗선을 맞춤), 최대 너비 880px. **게임이 열려 있는 동안에는 영상을 화면 밖으로 빼고 소리만 계속 낸다**(팀 결정, 유튜브 약관과 다름 — 명세 7장). 게임을 닫으면 다시 보인다. TV는 하나만 두고 보이기만 바꿔 음악이 끊기지 않게 한다.
  - 영상은 고정된 크기로만 본다(전체 화면 없음). 유튜브 자체 버튼은 없고, 영상에 마우스를 올리거나 눌러도 아무 반응이 없다. 화면 오른쪽 아래 반투명 알약에 [🔊 + 음량 막대]만 두고, 방장에게는 [❚❚/▶]가 하나 더 있다.
- **음악 조작**: **영상과 미니 바는 동시에 나오지 않는다.**
  - 평소: TV 테두리 안 화면 아래에 **리모컨**처럼 붙는다 — 현재 곡·신청자, 재생 위치 막대(경과/전체 시간), 대기큐 펼치기, 곡 신청. 따로 떨어진 음악 바는 없다.
  - 게임 중: 헤더 오른쪽의 **한 줄 미니 위젯**(둥근 알약 모양, 아래 테두리에 얇은 진행선).
  - 본인이 신청한 곡에만 [취소]가 보인다. 자동 재생이 막히면 [▶ 같이 듣기]가 나온다.
  - **기능 하나당 버튼 하나**: 평소에는 일시정지·음량은 영상 위 알약에만, 다음 곡·대기열·곡 신청·재생 위치는 리모컨에만 둔다. 게임 중에는 미니 위젯 하나에 모은다.
  - 방장에게만: 일시정지·재생, 다음 곡, 명령어 도움말(?), **리모컨 진행 막대 끌어서 위치 옮기기**. 다른 사람에게는 이 버튼이 아예 보이지 않고 진행 막대는 보기만 한다.
  - 일시정지 중에는 영상 위를 우리 일시정지 화면(❚❚ + 안내 문구)으로 덮어 유튜브의 멈춤 화면이 보이지 않게 한다.
- **채팅**: 내 메시지와 남의 메시지는 정렬로 구분하고, 말풍선 색은 `surface-2` 하나로 통일. `/`를 입력하면 방장 명령어 자동완성(방장에게만).
- **참가자 목록**: 채팅 위 접이식. 방장은 👑, 친구는 `--color-online` 점.

## 5. 메인 화면

- 사이트 첫 화면은 로비와 같은 배경(은은한 햇살 번짐, `.soft-light`) 위에 두 개의 입구: **방 만들기·들어가기**(라운지), **캠퍼스 플래너**(로그인 전에는 불 꺼진 문 + 자물쇠, 로그인하면 불 켜진 문).
- 오른쪽 위: 로그인 전 [로그인], 로그인 후 "닉네임님 [로그아웃]".
- 로그인 화면(`shared/auth/LoginPage.tsx`)은 메인과 같은 배경 위 카드 하나. 로그인·회원가입을 한 카드에서 바꾼다. 캠퍼스 플래너에 게스트로 들어가도 같은 화면이 나온다.

## 6. 움직임

- **힘을 주는 장면은 하나**: 로비에서 창문을 누르면 그 창문이 확대되며 방 화면으로 전환 (약 400ms).
- 나머지는 사용자 행동에 대한 반응만: 곡이 바뀔 때 음악 바 내용 교체, 메시지 도착, 버튼 눌림.
- 섹션·카드가 하나씩 떠오르는 등장 효과, 모든 카드의 마우스 오버 효과는 쓰지 않는다.
- `prefers-reduced-motion`이면 전환 효과 없이 바로 바꾼다.

## 7. 문구

- 짧은 해요체. 기술 용어 대신 사용자가 아는 말 ("소켓 연결 끊김" ✗ → "연결이 잠깐 끊겼어요. 다시 연결하는 중이에요" ✓).
- 버튼은 누르면 일어나는 일 그대로, 흐름 내내 같은 단어: "방 만들기" → "방을 만들었어요", "곡 신청" → "신청했어요".
- 오류는 무엇이 문제고 어떻게 하면 되는지: "비밀번호가 달라요. 4번 더 시도할 수 있어요", "방장이 입장을 잠근 방이에요".
- 빈 화면은 다음 행동을 안내: 대기큐가 비면 "다음 곡이 없어요. 듣고 싶은 곡을 신청해보세요".

## 8. 접근성 기본

- 글자와 배경의 명암비 4.5:1 이상 (토큰 조합은 이 기준으로 골랐다. 새 조합을 만들면 확인).
- 키보드로 모든 기능 사용 가능, 포커스 테두리는 `--color-light` 2px로 항상 보이게.
- 색만으로 상태를 전달하지 않는다 (잠금은 아이콘도, 온라인은 점과 글자도).
- 터치 영역 최소 44×44px.

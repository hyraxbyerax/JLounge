# 디자인 가이드 — "불 켜진 창문들"

> 화면을 만들 때 이 문서를 따른다. 여기 없는 결정은 이 문서의 컨셉에 맞게 고르고, 크게 벗어나면 사용자에게 먼저 묻는다.

## 1. 컨셉

전북대 학생들이 공강 시간에 **밤에 불이 켜진 건물**에 들르는 느낌이다.

- **로비 = 밤의 건물 외벽.** 방 하나하나가 **창문**이다. 이 창문 로비가 이 서비스에서 가장 기억에 남는 화면이 되도록 힘을 준다.
- **방 안 = 차분한 휴게실.** 로비에 쓴 과감함을 방 안에서는 덜어내고, 채팅·음악·게임이 편하게 보이게 한다.
- 화려한 효과를 여기저기 뿌리지 않는다. 힘을 주는 곳은 "창문 로비"와 "창문으로 들어가는 전환" 두 곳뿐이다.

## 2. 디자인 토큰

색과 글꼴은 **CSS 변수로 `apps/web/src/shared/styles/tokens.css`에 한 번만 정의**하고, 모든 화면은 변수만 쓴다. 색 값을 컴포넌트에 직접 쓰지 않는다. 스케줄러 화면도 같은 파일을 쓴다.

### 밤 모드 (라운지 기본)

| 변수 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--color-bg` | `#1E2140` | 기본 배경 (밤하늘). 완전한 검정은 쓰지 않는다 |
| `--color-surface` | `#2B2F57` | 패널, 채팅창, 대기큐 (벽) |
| `--color-surface-2` | `#363B6B` | 입력창, 선택된 항목, 패널 안의 구분 영역 |
| `--color-text` | `#ECEAF7` | 본문 글자 |
| `--color-text-muted` | `#A9A8C9` | 보조 글자, 시간, 안내 |
| `--color-light` | `#FFC86B` | 창문 불빛. 주요 버튼, 현재 재생 중, 켜진 창문 |
| `--color-light-text` | `#2A2110` | 불빛 색 위에 올리는 글자 |
| `--color-sofa` | `#8C5A9E` | 보조 강조. 방장 표시, 게임 영역 |
| `--color-online` | `#7FD8BE` | 접속 중, 친구 온라인, 성공 |
| `--color-danger` | `#F2768C` | 잠금, 강퇴, 오류 |

### 낮 모드 (스케줄 관리용, 같은 변수 이름)

스케줄 관리는 공부·일정 화면이라 밝은 모드를 쓴다. `[data-theme="day"]`에서 같은 변수를 바꿔 정의한다. 라운지는 밤, 스케줄은 낮이지만 같은 건물로 보이게 하는 것이 목표다.

| 변수 | 값 |
| --- | --- |
| `--color-bg` | `#EEF1F8` |
| `--color-surface` | `#FFFFFF` |
| `--color-surface-2` | `#E2E7F3` |
| `--color-text` | `#1E2140` |
| `--color-text-muted` | `#5B5F80` |
| `--color-light` | `#E9A43B` |
| `--color-light-text` | `#2A2110` |
| `--color-sofa` | `#7A4A8C` |
| `--color-online` | `#2E9C7E` |
| `--color-danger` | `#D14B63` |

### 글꼴

| 변수 | 글꼴 | 쓰는 곳 |
| --- | --- | --- |
| `--font-ui` | **SUIT** (가변 글꼴), 대체: `system-ui, sans-serif` | 화면 전체 |
| `--font-sign` | **고운바탕 (Gowun Batang)**, 대체: `serif` | 로비 제목, 창문 아래 방 이름, 방 안 상단의 방 이름. **그 외에는 쓰지 않는다** |

- 글자 크기 단계: 12 / 14 / 16(본문) / 20 / 28 / 40px. 이 단계 밖의 크기를 만들지 않는다.
- 굵기: SUIT 400(본문) / 600(버튼·강조) / 800(큰 제목). 고운바탕은 400·700.
- 영어 대문자 라벨, 제목 속 한 단어만 색 바꾸기, 제목 위의 작은 장식 라벨은 쓰지 않는다.

### 모양

- 모서리: 창문 `6px`(창틀 느낌), 패널 `12px`, 버튼·입력창 `10px`, 아바타·배지 원형. 모든 요소에 같은 모서리를 쓰지 않는다.
- 그림자는 거의 쓰지 않는다. 깊이는 배경과 `surface` 색의 차이로 만든다. **켜진 창문만** 불빛 번짐(`box-shadow`에 `--color-light` 반투명)을 준다.
- 간격 단위: 4px의 배수 (4, 8, 12, 16, 24, 32, 48).

## 3. 로비

```
┌──────────────────────────────────────────────────────┐
│ 전북대학교 휴식 라운지              [방 코드 입력] [방 만들기] │
│ (고운바탕)                                      [스케줄 관리] │
├──────────────────────────────────────────────────────┤
│                                                      │
│   ┌────┐   ┌────┐   ┌────┐   ┌────┐                  │
│   │ ✦✦ │   │ ✦  │   │ ░  │   │ ▤🔒│     ← 창문 = 방    │
│   └────┘   └────┘   └────┘   └────┘                  │
│   공강방      캐치마인드    조용한 방     잠긴 방           │
│   4/8 ♪곡명   진행 중 5/6   2/6          3/4              │
│                                                      │
│                              [입장 가능한 방만 보기]     │
└──────────────────────────────────────────────────────┘
```

### 창문 카드 상태

| 상태 | 모양 |
| --- | --- |
| 입장 가능 | 창문 안이 `--color-light`로 켜짐. 인원이 많을수록 더 밝게 (불투명도 단계 3개 정도) |
| 게임 진행 중 | 창문 안에 `--color-sofa` 빛이 섞임 + "진행 중" 표시 |
| 인원 가득 | 불은 켜져 있지만 창문 아래 인원이 `--color-text-muted`, 누르면 "방이 가득 찼어요" |
| 잠긴 방 | 블라인드가 내려진 창문(가로줄 무늬) + 자물쇠 아이콘. 목록 아래쪽에 배치 |

- 창문 아래에는 방 이름(고운바탕), 인원, 재생 중인 곡 또는 진행 중인 게임을 짧게.
- 정렬: 입장 가능한 방이 앞, 잠긴 방이 뒤. 필터 "입장 가능한 방만 보기".
- 방이 없을 때: 불 꺼진 창문들만 보이고 "아직 불 켜진 방이 없어요. 첫 방을 열어볼까요?" + [방 만들기].
- 휴대폰: 창문을 한 줄에 2개씩.

## 4. 방 안

### 데스크톱

```
┌────────────────────────────────────────┬───────────────┐
│ 공강방 (고운바탕)   👑방장 · 4/8   [초대] [설정] [나가기] │               │
├────────────────────────────────────────┤    채팅         │
│                                        │               │
│               무대                       │  시스템 메시지는 │
│   게임 중이 아니면: 라운지 TV(유튜브 플레이어) │  가운데 작은 글씨 │
│   게임 중이면: 게임 화면 + 작은 라운지 TV     │               │
│                                        │               │
├────────────────────────────────────────┤               │
│ ♪ 지금 재생 중  곡 제목 · 신청자   대기 3곡 ▾  [곡 신청]  │ [메시지 입력]   │
└────────────────────────────────────────┴───────────────┘
```

- **라운지 TV**: 유튜브 플레이어는 약관상 화면에 보여야 하므로 숨기지 않고, 방 안의 TV처럼 테두리를 둔 하나의 물건으로 디자인한다. 게임 중에도 최소 200×200px 이상 보이게 유지한다.
- **음악 바**: 화면 아래에 고정. 현재 곡, 신청자, 대기큐 펼치기, 곡 신청. 본인이 신청한 곡에만 [취소]가 보인다. 방장에게만 명령어 도움말 아이콘.
- **채팅**: 내 메시지와 남의 메시지는 정렬로 구분하고, 말풍선 색은 `surface-2` 하나로 통일. `/`를 입력하면 방장 명령어 자동완성(방장에게만).
- **참가자 목록**: 채팅 위 접이식. 방장은 👑, 친구는 `--color-online` 점.

├─────────────────────┤
│ [채팅] [대기큐] [참가자] │

## 5. 메인 화면

- 사이트 첫 화면은 로비와 같은 밤 건물 배경 위에 두 개의 입구: **방 만들기·들어가기**(라운지), **스케줄 관리**(로그인 필요 표시).
- 스케줄 관리는 지금 "준비 중" 화면. 누르면 로그인 안내 → 로그인 후 "준비 중".

## 6. 움직임

- **힘을 주는 장면은 하나**: 로비에서 창문을 누르면 그 창문이 확대되며 방 화면으로 전환 (약 400ms).
- 나머지는 사용자 행동에 대한 반응만: 곡이 바뀔 때 음악 바 내용 교체, 메시지 도착, 버튼 눌림.
- 섹션·카드가 하나씩 떠오르는 등장 효과, 모든 카드의 마우스 오버 효과는 쓰지 않는다.
- `prefers-reduced-motion`이면 전환 효과 없이 바로 바꾼다.

## 7. 문구

- 짧은 해요체. 기술 용어 대신 사용자가 아는 말 ("소켓 연결 끊김" ✗ → "연결이 잠깐 끊겼어요. 다시 연결하는 중이에요" ✓).
- 버튼은 누르면 일어나는 일 그대로, 흐름 내내 같은 단어: "방 만들기" → "방을 만들었어요", "곡 신청" → "신청했어요".
- 오류는 무엇이 문제고 어떻게 하면 되는지: "비밀번호가 달라요. 4번 더 시도할 수 있어요", "방장이 입장을 잠근 방이에요".
- 빈 화면은 다음 행동을 안내: 대기큐가 비면 "다음 곡이 없어요. 듣고 싶은 곡을 신청해보세요".

## 8. 접근성 기본

- 글자와 배경의 명암비 4.5:1 이상 (토큰 조합은 이 기준으로 골랐다. 새 조합을 만들면 확인).
- 키보드로 모든 기능 사용 가능, 포커스 테두리는 `--color-light` 2px로 항상 보이게.
- 색만으로 상태를 전달하지 않는다 (잠금은 아이콘도, 온라인은 점과 글자도).
- 터치 영역 최소 44×44px.
